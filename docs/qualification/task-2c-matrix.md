## Interruptions and limits

The integrated test separates proposal creation, rejection/ignore, concurrent decision, committed-but-not-dispatched authority and fresh-runner dispatch. Task 1's existing `native-recovery-lifecycle` job additionally injects actual-host interruption, changed tracked/new/deleted files, fresh-runner restoration, and missing/expired trusted evidence. These retained tests are reused rather than represented as additional interruptions of the same integrated run.

Seven-day diagnostic retention remains unchanged. Abrupt termination can lose changes after the last durable checkpoint; unavailable or expired trusted evidence fails closed. Recovery does not mint authority or replay an uncertain provider request.

External GitHub/Vercel metadata and provider/identity transports are synthetic. Final Chromium runs against the actual immutable local candidate and feeds the real preview receipt validator. This does not qualify deployed-mode browser networking, Vercel deployment protection, production synthetic publication, or paid-model performance. Production merge verification is separate, read-only and nonbillable.
