## Corrections implemented against Phase 1 defects

1. **Durable identity and page-count provenance:** `lib/documents/continuity.ts` records a source-linked document contract; `app/api/chat/route.ts` binds it to the existing durable `chat_task_progress` record; history-window recovery preserves the contract. Current explicit requirements supersede inherited ones; new/unrelated documents do not borrow an earlier cap. Same-source saved exports reuse only matching provenance.
2. **Measured natural-reflow candidate selection:** `lib/documents/production.ts` evaluates actual DOCX→Chromium PDF output for standard, less-spaced standard, and 11pt compact single-section candidates before inserting Word section boundaries. Exact requested page counts and genuine PDF glyph checks remain mandatory. The existing measured pagination repair remains available when natural candidates cannot satisfy every hard constraint.
3. **Semantic continuity:** `lib/documents/generate.ts` retains heading support and the first substantive bullet, with bounded penalties on splitting heading metadata, bullet groups and numbered clauses. It does not force oversize groups to fit, discard text or add résumé-specific formatting.
4. **Actionable review:** `lib/documents/design.ts` supports bounded `natural-reflow`, `compact-layout` and `group-continuity` actions in addition to existing hierarchy and rhythm changes. Every candidate must be regenerated, rasterized and mechanically validated before adoption. Existing provider selection and owner accounting remain unchanged.
5. **Page composition:** after obtaining a mechanically valid candidate, the producer tries at most two bounded paragraph-rhythm increases (up to spacing=8), only keeping changes that preserve page count, source and clean rendering. This fills avoidable blank space without shrinking body text.
6. **Delivery truthfulness:** `produceDocument(requireProfessionalAcceptance=true)` rejects unresolved visual review; standard technical-only output remains possible where not explicitly prohibited, but `storage.ts` marks it honestly instead of claiming professional inspection. Authenticated readback, receipt hashes, private storage and authorization logic are intact.
